# Vite + React

## Getting started

```bash
npm install
```

## Customize your portfolio

- Update text/links/projects in `src/data/portfolio.js`
- Replace the profile image at `public/profile.svg` (keep the same filename, or update `profilePhotoUrl`)

### Dev server

Runs Vite via nodemon (auto-restarts when config/env files change):

```bash
npm run start
```

Runs Vite directly (normal HMR flow):

```bash
npm run dev
```

### Build / preview

```bash
npm run build
npm run preview
```
